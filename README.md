🔮 赛博占卜终端 (Cyber Divination Terminal)

这是一个基于 Node.js 与 DeepSeek API 构建的轻量级终端算卦工具。它利用底层密码学模块生成物理级真随机数来模拟传统的“三枚铜钱”起卦过程，并调用 DeepSeek 大模型为你进行极具赛博风格的六爻解卦。



🚀 快速开始



1\. 环境要求

确保你的电脑上已安装 Node.js (v18 或更高版本)。



2\. 获取代码

bash

git clone https://github.com/huangnaisheng/ai-fortune-teller-.git



3.运行

node gua.js



4\.首次配置

第一次运行时，程序会提示你输入 DeepSeek 的 API Key (sk-...)。

填入后，程序会自动生成 config.json，之后再运行便会直接进入算卦界面。
